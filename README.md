# 덕성여자대학교 웹 배리어프리맵 (TwinVision)

**웹 서비스: https://hyelynkim21.github.io/duksung-barrierfree-map/**

2026 미래인재대학 학술제 연구 「디지털 트윈 기반 배리어프리 웹 3D 캠퍼스 맵 개발: 덕성여자대학교 접근성 정보 제공을 중심으로」의 소스 코드입니다.

- 접근성 지도: 건물·출입구·장애인 화장실·엘리베이터·장애인 주차구역의 접근성 수준(원활·일부 제약·어려움·정보 없음)과 현장 확인일 표시, 검색·필터·목록 보기, 휠체어 경로 탐색
- 3D 캠퍼스: Blender로 만든 캠퍼스 모델(외형 참고용)
- 변경 소식: 시설 변경 소식과 갱신 방식 안내

## 폴더 구성

| 경로 | 내용 |
| --- | --- |
| `index.html` | 웹 서비스 본체 (접근성 지도, 경로 탐색, 변경 소식) |
| `detail-viewer.js` | 3D 캠퍼스 뷰어 (three.js) |
| `data/` | 건물 외곽선·길 데이터 (GeoJSON) |
| `models/` | 3D 캠퍼스 모델 (glb) |
| `photos/` | 연구자가 직접 촬영한 시설 사진 |
| `icons/` | 아이콘 |
| `analysis/` | 보고서 Ⅴ장 접근성 경로 분석 코드와 결과 |

접근성 정보(시설·길·소식·사진 목록)는 구글 시트에서 읽어 옵니다.
